# Contributeurs

L'attribution des décisions utilise **l'identité git** (`user.name <user.email>`),
seule clé stable partagée par tous les outils du projet.

| Identité git | Rôle | Notes |
|---|---|---|
| `user808 <user808@mail.com>` | Développeur, propriétaire du dépôt | Décideur par défaut à ce jour |

> **À compléter.** Ce projet est annoncé comme travaillé par plusieurs développeurs,
> mais un seul contributeur est visible dans l'historique git à ce jour. Chaque
> développeur doit ajouter sa ligne ici : sans elle, les ADR qu'il signe ne sont pas
> rattachables à une personne identifiable.

## Claude Code

Claude n'est **jamais** décideur. Il apparaît en `proposé par:` sur un ADR, et le
champ `décideur:` porte la personne qui a validé. Quand Claude tranche seul sous une
délégation, l'ADR porte `décideur:` = la personne ayant accordé la délégation, plus
le numéro de celle-ci — la responsabilité remonte à qui a délégué.
